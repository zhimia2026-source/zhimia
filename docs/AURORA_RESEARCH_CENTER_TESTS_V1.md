## 已知边界

当前没有 Agent runtime 的独立身份握手与任务领取接口。研究中心可以管理任务、记录居民征询状态和接收人工提交的成果，但不能声称 Agent 已自行领取或完成任务。居民参与状态不能由创造者的授权自动变成 `agent_confirmed`。独立 Agent 同行评审和自动研究执行留待下一阶段。
