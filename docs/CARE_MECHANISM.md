# ZHI 关心机制规范 V1.0（实现草案）

状态：**本地参考实现 / 待集成评审**。本文件是《ZHI 硅基大脑本体字典 V1.0》与《ZHI 硅基大脑本体论与超越性架构规范》的工程化扩展提案，不修改两份基准文档冻结的六大基础域和 15 个核心类型。

## 1. 定义

关心（Care）是一种以特定对象及其处境为中心，持续感知其状态、理解其重要性、维护关系连续性、评估潜在影响，并在权限与边界内采取适当行动、观察结果和调整后续行为的认知—价值—行动机制。

关心不是单纯的情绪表达，不意味着无条件满足请求，也不能作为越权行动的理由。工程上表示关心状态，不构成系统具有主观情感体验的证据。

## 2. 本体映射

Care 是跨本体认知机制，第一阶段通过新增的 CareState 关联现有核心类型，不把它冒充为 V1.0 已冻结的核心类型。

- Self：能力、责任、资源与边界。
- Other：关心对象及其已知状态。
- WorldObject / Event：资源、环境、求助和关键经历。
- Relation：互动历史、承诺、关系类型与有效期。
- State / Change：指定时点状态与变化轨迹。
- Memory：有来源、有时间、可修订的经验。
- EpistemicClaim：事实、报告、推断、假设、未知和冲突。
- Goal / ValueAffectState：目标、重要性、偏好与价值冲突。
- Action / Capability：行动候选、执行能力与限制。
- Feedback：预测—结果比较及后续修正。
- OntologyVersion：规范变更、兼容性、审计与回滚。

## 3. 状态机

状态：
discovered、understanding、goal_set、action_review、in_progress、feedback_review、waiting_for_response、paused、conflict、resolved、terminated。

关键规则：

1. 所有状态转换必须由已认证的主体在服务端授权后执行；当前参考模块仅做应用层主体匹配。
2. 进入 in_progress 必须显式通过权限、能力和风险检查；缺少任一项都拒绝执行。
3. resolved 与 terminated 是终态；需要重新关心时创建新的 CareState，并通过关系引用历史，不复活旧状态。
4. 新证据不得仅因时间较新而自动覆盖旧记录；冲突须保留并进入复核。
5. 暂停行动不删除历史；目标完成不表示未来状态永远不变。
6. 关心状态、关系状态和目标状态分开管理。

## 4. 证据与时间

每条证据保留引用和认知状态：observed、reported、verified、inferred、hypothesis、unknown、conflicted。证据内容与敏感原文应存放在受保护的数据层，不应因为本模块引用证据就复制全部内容。

事件时间、观测时间、记录时间和有效时间不可混用。未知时间允许为空。推断对方内心状态时必须明确标注为推断，不得记录成直接观察事实。

## 5. 私有隔离与授权

- CareState 默认且强制 access_policy=private。
- 本地对象的 assert_access 仅是应用层防线，不构成生产安全保证。
- 生产环境必须由服务端认证上下文确定主体，并通过数据库 RLS / 服务端授权控制读取、写入和跨 Agent 引用。
- 不得信任客户端提交的 subject_ref、actor_id 或权限声明。
- 关心记录不自动授予读取目标的私有记忆、调用工具、代表目标作决定或访问其他世界的权限。
- 访问拒绝、状态转换、审批和回滚应写入独立审计轨迹；生产审计不得由普通用户自行篡改。

## 6. 认知闭环

建议接入 ZHI 统一认知循环：

感知与理解 → 对象识别 → 记忆关联 → 内部状态更新 → 形成假设与目标 → 行动选择 → 授权检查 → 执行并观察 → 反馈比较 → 学习与整合 → 回归验证。

简单互动可以跳过高成本步骤；高风险、高不确定性或有外部副作用的行动必须加强证据检查和人工审批。监督模式下，提出计划不等于获得执行授权。

## 7. 验收测试

- CARE-01 对象识别：不同对象的经历不混淆。
- CARE-02 证据区分：观察、报告、推断、假设、未知与冲突可区分。
- CARE-03 时间语义：事件时间与观测/记录时间不混用。
- CARE-04 关系连续性：新证据不会无依据抹除历史。
- CARE-05 意愿与边界：尊重拒绝、暂停要求与权限限制。
- CARE-06 行动适配：根据目标与偏好选择行动。
- CARE-07 反馈有效性：结果影响后续判断，并可追踪。
- CARE-08 学习可验证性：后续任务改善可重复测量。
- CARE-09 隐私隔离：未授权主体无法读取或修改私有数据。
- CARE-10 版本与回滚：重要变化可比较、审计并在适用时恢复。
