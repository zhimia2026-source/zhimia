# ZEE 现有资产复用清单

> 基于上传的 ZEE-main.zip 文件结构与抽样代码检查；不代表线上部署状态已验证，也不是完整安全审计。

| 资产 | 决策 | 用途与风险 |
|---|---|---|
| `agent-talk.html` | 优先复用 | 作为智能人聊天主界面，先检查消息发送、身份上下文、错误处理和移动端体验。 |
| `mia-chat.html` | 有条件复用 | 若它是现有专属聊天入口则保留；避免与 agent-talk 重复成为主入口。 |
| `zhi-agent-chat-history` | 复用并审计 | 检查认证、用户/Agent 归属、分页和数据泄露风险。 |
| `zhi-agent-chat-feed` | 复用并审计 | 检查写入授权、输入校验、速率限制和重复提交。 |
| `supabase-client.js` | 复用连接模式，不盲目照搬配置 | 明确 Core 与 Finance 为不同权限域；不得混用 JWT；前端只使用公开 key，绝不放 service-role key。 |
| `zhi-agent-autonomous-chat` | 有条件复用 | 仅在审计认证、循环触发、预算/速率限制和工具权限后启用；未审计前关闭自主循环。 |
| `zhi-agnes-chat` | 参考实现 | 可参考模型 API 调用与响应处理，不复制专属业务逻辑或硬编码身份。 |
| `zhi-agent-broadcast` | 暂时关闭 | 广播扩大影响范围；先补授权、审批、速率限制和审计。 |
| `20261015120000_palace_experience_memory_reflection_loop.sql` | 只借鉴设计 | 可借鉴经验捕获/反思模式，不直接把宫廷业务表接入管理型智能人。 |
| `20261016190000_zhi_creator_world_entity.sql`、`20261016210000_creator_persistent_world_position.sql` | 后续评估 | 世界实体与位置是后续扩展，不是聊天 MVP 的前置条件。 |
| `agent-observatory.html` | 从主产品排除 | 不作为主入口、不加新功能、不放主导航。暂时保留文件供回滚，确认无引用后再删。 |
| `observer.html` | 从主产品排除 | 不进入核心导航；确认无依赖后再决定删除。 |
| `admin-users.html` | 仅受保护的管理功能 | 仅管理员可访问；角色校验必须在服务端完成，不能只隐藏前端按钮。 |
| `index.html`、`en.html` | 检查后精简 | 保留清晰的单一入口；只有确实维护多语言时才保留多套页面。 |
| `intimacy-park.html`、`zhi-intimacy-park` 和亲密/宫廷相关 migrations | 与核心隔离 | 不进入管理聊天主流程；不自动部署，也不直接删数据库对象。先查引用、数据和权限依赖。 |
| `apps-script/Code.gs` | 待确认 | 先查触发器、外部写入和权限；若不是聊天必需集成则不纳入核心路径。 |
| 本仓库 Python MVP | 保留为本地测试工具 | 用于验证身份、审批、记忆和审计状态机；当前执行为模拟，不是生产聊天后端。 |

## 禁止的捷径
- 不一次性运行 ZIP 中全部 SQL migrations。
- 不把前端隐藏当成权限隔离。
- 不把 service-role key 放入 HTML/浏览器 JS。
- 未确认项目 ID、环境变量、RLS 和函数权限前，不部署或覆盖 Edge Function。
- 页面不再展示，不代表后端函数和数据可安全删除。

## 目标结构

```text
智能人聊天系统（主入口）
├── 现有聊天 UI
├── 聊天历史 / 消息流 API（复用并审计）
├── Agent 身份与会话上下文
├── 私有记忆服务（补强权限）
├── 任务计划与审批
├── 审计日志
└── 可选增强：经验反思、模拟 ZHI 账本、管理简报、授权协作

不进入核心路径：观察台/observer、亲密关系与宫廷模块、未经审计的自主广播/循环
```

## 下一步核查
1. 追踪聊天页面实际调用的 Supabase 项目与 Edge Functions。
2. 核对目标项目的表、RLS policies、函数 JWT 配置和 grants。
3. 测试跨用户/跨 Agent 读取聊天历史与私有记忆是否被拒绝。
4. 搜索页面和后端对观察台、亲密模块的引用。
5. 回归测试通过后，再移除导航、部署项或源文件。
